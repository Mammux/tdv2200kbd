TDV 2200 USB Adapter

A Raspberry Pi Pico and one MAX3490 transceiver connect the keyboard's RS-422 link to USB. The keyboard sends at 2400 baud and takes commands at 600 baud, 8N1 in both directions.

No termination resistor is needed at 2400 baud over a short cable. Check the MAX3490 pin numbers against its datasheet before soldering.

Why this works

The keyboard's AM26LS32 receiver switches at ±200 mV, so the MAX3490's driver at 3.3 V supply (about 2 V differential) is well within spec.

The MAX3490's receiver accepts common-mode voltages from −7 V to +12 V, so the AM26LS31's 5 V output is no problem.

The RP2040 UARTs use the same baud rate for TX and RX, so receiving and sending go through separate UARTs: UART0 receives at 2400, UART1 sends at 600.

Bring-up

  1. Confirm power pins on the keyboard.

    Keyboard unpowered: DE-9 pin 3 should beep to AM26LS31 pin 16, and pin 6 to pin 8.

  2. Install CircuitPython.

    Download the UF2 for your board from circuitpython.org. Hold BOOTSEL while plugging in the Pico, then drop the UF2 onto the RPI-RP2 drive. It restarts as CIRCUITPY.

  3. Copy the sniffer.

    Save code.py (below) to the CIRCUITPY drive. It runs straight away.

  4. Check voltages before connecting the keyboard.

    About 5 V between DE-9 pins 3 and 6, and 3.3 V across MAX3490 pins 1 and 4.

  5. Connect the keyboard and watch the current.

    A USB power meter is ideal. If the draw is far above what a keyboard should need, or near 500 mA, unplug and investigate.

  6. Open the serial console and press keys.

    Thonny, Mu, tio /dev/ttyACM0 or PuTTY all work. Each key should produce a line of hex bytes.

  7. If the output is garbage,

    swap the wires on DE-9 pins 9 and 4. If there is no output at all, the keyboard may be waiting for an enable command from the host. Try sending a few bytes from the console, or sniff the real terminal at power-on.

  8. Record a code for every key

    and note whether releases send anything. That table drives the next phase: the USB keyboard firmware.

Sniffer firmware

Pinout from your own trace, matching a 2013 J2–DE9 cable table for the same keyboard. Protocol: UART 8N1, 2400 baud from the keyboard and 600 baud to it.
